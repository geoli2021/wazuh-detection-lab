# 🛡️ Active Directory & Wazuh SIEM Detection Engineering Lab

## 📌 Visão Geral do Projeto
Este projeto consiste em um ambiente controlado de laboratório para **Engenharia de Detecção**, simulação de cenários de ataque (Red Team) e validação de regras de monitoramento em tempo real com **Wazuh SIEM** e **Sysmon** (Blue Team).

O objetivo principal foi simular táticas e técnicas do ecossistema **MITRE ATT&CK** contra um domínio Active Directory e desenvolver regras customizadas no SIEM para detecção proativa de anomalias.
